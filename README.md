## 🚀 Featured Projects

### 🎙️ AI Meeting Assistant & Real-Time Transcriber

A cross-platform desktop application for **real-time microphone and system-audio transcription**.

Built with **Rust + Tauri + React**, the application captures multiple audio sources, processes them through a Rust audio pipeline, and supports both local and cloud-based speech recognition.

**Highlights**

* 🎤 Simultaneous microphone + system audio capture
* ⚡ Real-time speech-to-text
* 📴 Offline transcription using `whisper.cpp`
* ☁️ Cloud transcription using Groq
* 🦀 Rust-based audio processing
* 🪟 WASAPI loopback for system audio
* 🔄 Runtime switching between STT engines

**Stack:** Rust · Tauri · React · TypeScript · CPAL · Whisper.cpp · Groq

→ [View Repository](https://github.com/naimekattor/sytem-level-mic-and-speaker-tracker-desktop-app)

### 🎓 EduGuide — AI University Admission Assistant

An AI-powered platform designed to help Bangladeshi students understand university admission requirements and discover suitable institutions.

The system combines **structured university data, semantic search, RAG, and LLM-based responses** to provide contextual admission guidance.

**Highlights**

* 🔎 Semantic search over university information
* 🤖 AI-powered admission assistance
* 🎯 Eligibility-based guidance
* 🧠 RAG-powered contextual answers
* 🗃️ Vector search with Qdrant
* 🔌 Multi-provider LLM architecture

**Stack:** Next.js · TypeScript · Qdrant · Drizzle · PostgreSQL · Ollama · OpenAI · Anthropic

→ [View Repository](https://github.com/naimekattor/university-admission-assistant)
